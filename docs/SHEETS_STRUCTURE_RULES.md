# Правила структуры и форматирования листов

Этот документ является реестром правил для структуры и оформления Google Таблиц в проектах AgentCare. Агенты обязаны сверяться с этим файлом при любых изменениях в структуре данных.

## Глобальные правила
1. **Эталон структуры**: Проект **SK** является мастер-шаблоном структуры листов.
2. **Язык**: Заголовки и примечания на листах ведутся на русском языке (где применимо).
