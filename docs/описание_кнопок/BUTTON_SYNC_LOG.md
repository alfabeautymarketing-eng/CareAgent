# 📋 Кнопка: Журнал синхронизации

**Файл:** `BUTTON_SYNC_LOG.md`
**Функция GAS:** `showSyncLogDialog`
**Функция сервера:** `GET /api/v1/sync-logs/{spreadsheet_id}`
**Исполнитель логики:** `src/services/sync_log_service.py` (класс `SyncLogService`)
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Открывает журнал операций синхронизации. Показывает историю всех выполненных синхронизаций: какие строки были синхронизированы, какие правила применены, были ли ошибки. Полезен для отладки и аудита работы системы синхронизации.

**Ключевые особенности:**
- Хранение журнала на сервере (не в Google Sheets).
- Фильтрация по дате, статусу, типу операции.
- Статистика: количество операций, успехов, ошибок.
- Возможность экспорта журнала в JSON/CSV.
- Автоматическая ротация старых записей (настраиваемый retention).

---

## ⚙️ Алгоритм работы

### Фаза 1: Открытие журнала (GAS)
1. **Пользователь** нажимает кнопку "📋 Журнал синхронизации" в меню.
2. **GAS** определяет `spreadsheet_id` текущей таблицы.
3. **GAS** открывает интерфейс просмотра журнала (диалоговое окно или веб-страница).

### Фаза 2: Загрузка данных (Server)
4. Интерфейс запрашивает `GET /api/v1/sync-logs/{spreadsheet_id}` с параметрами фильтрации:
   - `limit` — количество записей (по умолчанию 50).
   - `offset` — сдвиг для пагинации.
   - `status` — фильтр по статусу (success/error).
   - `date_from` / `date_to` — диапазон дат.
5. **Server** читает файл журнала из `data/sync_logs/`.
6. **Server** применяет фильтры и возвращает записи с общим количеством.

### Фаза 3: Отображение (UI)
7. Интерфейс отображает таблицу записей:
   - Время операции
   - Тип (sync_row / sync_full / sync_event)
   - Лист-источник
   - Артикул (ключ строки)
   - Количество примененных правил
   - Статус (успех / ошибка)
   - Детали ошибки (если есть)

## 📋 Доступные API-эндпоинты журнала

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/api/v1/sync-logs/{spreadsheet_id}` | GET | Список записей журнала |
| `/api/v1/sync-logs/{spreadsheet_id}/stats` | GET | Статистика синхронизации |
| `/api/v1/sync-logs/{spreadsheet_id}/export` | GET | Экспорт в JSON/CSV |
| `/api/v1/sync-logs/{spreadsheet_id}/truncate` | POST | Очистка старых записей |

## ⚠️ Важные замечания

- Журнал хранится локально на сервере, не в Google Sheets.
- Старые записи автоматически удаляются по настройке `sync_log_retention_days`.
- Максимальное количество записей ограничено параметром `sync_log_max_entries`.
- Для очистки журнала используйте endpoint `truncate` или настройте автоматическую ротацию.
