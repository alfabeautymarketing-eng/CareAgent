**Файл:** `BUTTON_01_OBRABOTKA_SK.md`
**Функция сервера:** `POST /api/v1/price/process/sk`
**Функция GAS:** `serverProcessPrimaryData` -> `callServerProcessPrice("sk", "all")`
**Исполнитель логики:** `src/services/price_processor.py` (Class `PriceProcessor`)
**Конфигурация:** `config/projects/sk.yaml`

---

## Описание

Кнопка "Обработка" для проекта SK (Carmado) запускает полный цикл обработки прайс-листа. Отличается от MT тремя ключевыми особенностями:

1. **Парсинг по пустым значениям** — группы товаров определяются по пустому CODE и заполненному PRODUCT (аналогично MT, но без колонки CATEGORY)
2. **Скидка 20%** — на листе "Динамика цены" автоматически заполняется фиксированная скидка
3. **Комбинированная группа** — формат `"{Линия} - {Группа}"` вместо простой группы

**Обрабатывается в 2 последовательных цикла:** main -> probes

## Поиск начала данных в исходных листах

### Лист "-Б/З поставщик" (main)

Строки 0–19 — юридическая шапка (название компании, адрес, условия поставки). Парсер пропускает их через `data_start_row: 20`. Заголовков "CODE"/"PRODUCT" нет — используются фиксированные индексы колонок из конфига.

Начиная со строки 20, группы определяются по **пустым значениям**:
- Колонка B заполнена AND колонка C пуста → **строка группы**
- Колонка B заполнена AND колонка C заполнена → **артикул**

Формат группы в колонке B:
- `"SkinClinic - FACIAL CARE"` → Линия=SkinClinic, Группа=FACIAL CARE
- `"BODY CARE"` → Линия=(пусто), Группа=BODY CARE

Комбинированная группа: `"{Линия} - {Группа}"`

**Индексы колонок (sk.yaml → parser.main.excel_columns):**

| Индекс | Колонка | Содержимое |
|--------|---------|-----------|
| 1 | B (CODE) | Артикул производителя |
| 2 | C (PRODUCT) | Название товара |
| 5 | F (UNITS) | MASTER BOX / шт. в уп. |
| 6 | G (PRICE) | DISTR. PRICE / Цена EXW |
| 8 | I (RRP) | Рекомендованная розничная цена |

### Лист "-Пробники" (probes)

Строки 0–10 — шапка компании (Carmado S.L., адрес, MARKETING MATERIALS). Строка 11 — заголовки. Данные начинаются со строки 12 (`data_start_row: 12`).

Определение групп:
- Артикул начинается с `"00"` (напр. `"0001CARM3"`) → **товар**
- Артикул не начинается с `"00"` (напр. `"ANTI-AGING"`) → **группа**

Стоп-маркер: строка с `"CATÁLOGOS Y MATERIALES IMPRESOS"` — прекращает парсинг.

**Индексы колонок (sk.yaml → parser.probes.excel_columns):**

| Индекс | Колонка | Содержимое |
|--------|---------|-----------|
| 0 | A (REFERENC.) | Артикул пробника |
| 1 | B (PRODUCT) | Название товара |
| 5 | F (UNITS) | Количество |
| 6 | G (PRICE) | Цена |

**Особенности SK:**
- Нет отдельной колонки "Объём" (volume) — остаётся пустым
- Нет штрихкода в прайсе поставщика
- RRP есть только в main (отсутствует в probes, MT и SS)

## Отличия от MT: Скидка на "Динамика цены"

SK имеет дополнительный шаг: после копирования цен на "Динамика цены", в колонку "СКИДКА ОТ EXW" записывается фиксированное значение **20%** (0.2) для всех строк с ценой.

Также SK поддерживает категорийные скидки (настраиваются в конфиге):

| Категория | Скидка |
|-----------|--------|
| Уход | 10% |
| Макияж | 15% |
| Парфюмерия | 5% |
| Волосы | 8% |
| По умолчанию | 0% |

---

## Отличия от MT: Очистка ID-L

SK имеет дополнительный шаг очистки: помимо стандартных ID-P, ЦЕНА EXW, ID-G, также очищается колонка **ID-L** (Линия) на всех листах. Это SK-специфичная особенность, связанная с комбинированной группой "Линия - Группа".

---

## Алгоритм работы (пошагово)

Общий алгоритм совпадает с MT (15 шагов), со следующими отличиями:

### Шаг 7 (Чтение данных) — только значения

```
values = ws.get_all_values()
# Цвета фона НЕ читаются (в отличие от прежней версии)
```

### Шаг 8 (Парсинг) — по пустым значениям

```
current_group = ""
current_line = ""

Для каждой строки после заголовков:

    code = row[CODE_COL]       <- Колонка A
    product = row[PRODUCT_COL] <- Колонка B

    Если code пуст AND product пуст:
        -> Пропускаем (пустая строка)
        -> continue

    Если code пуст AND product заполнен:
        -> Это строка группы
        -> Если product содержит " - ":
            -> current_line = часть до " - "
            -> current_group = часть после " - "
        -> Иначе:
            -> current_group = product
        -> continue

    Если code заполнен AND product заполнен:
        -> Это артикул
        -> combined_group = "{current_line} - {current_group}"
        -> Парсим UNITS, PRICE, RRP
        -> Создаём ParsedRow
```

### Шаг 9 (Очистка) — дополнительно ID-L

Очищаются те же колонки что и в MT, плюс:
- **ID-L** на всех листах (SK-специфично)

### Шаг 14 (Формулы) — скидка 20%

Перед записью формул, для SK в колонку "СКИДКА ОТ EXW" записывается:
- **0.2** (20%) для всех строк с непустой ценой
- Формула EXW ALFASPA = EXW * (1 - 0.2) = EXW * 0.8

## Обработка ошибок (SK-специфичные)

| Ситуация | Поведение |
|----------|-----------|
| Заголовки не требуются | Используются фиксированные индексы из конфига (main: 1,2,5,6,8; probes: 0,1,5,6) |
| Формат группы без " - " | Вся строка = группа, линия сохраняется от предыдущей группы |
| Ошибка в любом цикле | Ошибка записывается в Логи + возвращается GAS-клиенту для отображения toast |
| Все циклы завершились с ошибкой | Статус "error" + сообщения об ошибках в ответе |

Остальные ошибки обрабатываются аналогично MT (см. BUTTON_01_OBRABOTKA_MT.md).
