# 📜 Кнопка: Журнал логов

**Файл:** `BUTTON_LOG_DASHBOARD.md`
**Функция GAS:** `openLogDashboard_proxy`
**Функция сервера:** `GET /api/v1/logs-ui`
**Исполнитель логики:** `src/api/endpoints.py` (endpoint `logs-ui`), `src/services/function_log_service.py`
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Открывает веб-интерфейс журнала логов сервера в браузере. Показывает подробные логи выполнения всех серверных функций: обработки данных, синхронизации, экспорта и т.д. В отличие от "Журнала синхронизации", который фокусируется на операциях sync, Журнал логов содержит детальные записи выполнения ВСЕХ функций системы.

**Ключевые особенности:**
- Открывается в браузере как веб-страница (а не в Google Sheets).
- Показывает логи всех серверных функций (не только синхронизации).
- Детализация: время начала/окончания, параметры, результат, ошибки.
- Реальное время: можно наблюдать за выполнением операции в процессе.
- Поддержка фильтрации по функции, статусу, дате.

---

## ⚙️ Алгоритм работы

### Фаза 1: Открытие дашборда (GAS)
1. **Пользователь** нажимает кнопку "📜 Журнал логов" в меню.
2. **GAS** вызывает функцию `openLogDashboard_proxy`.
3. **GAS** формирует URL: `{SERVER_URL}/api/v1/logs-ui`.
4. **GAS** открывает модальное окно или новую вкладку с этим URL.

### Фаза 2: Загрузка интерфейса (Server)
5. **Server** обрабатывает `GET /api/v1/logs-ui`.
6. **Server** возвращает HTML-страницу с дашбордом логов.
7. Дашборд загружает данные через API-эндпоинты логов.

### Фаза 3: Работа с дашбордом (Browser)
8. Пользователь может:
   - Просматривать список всех выполненных функций.
   - Фильтровать по имени функции, статусу, дате.
   - Открывать детали конкретного выполнения (параметры, шаги, результат).
   - Экспортировать логи.

- Для работы требуется доступ к серверу (SERVER_URL должен быть настроен).
