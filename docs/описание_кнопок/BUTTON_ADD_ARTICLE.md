# ➕ Кнопка: Добавить артикул

**Файл:** `BUTTON_ADD_ARTICLE.md`
**Функция GAS:** `addArticleManually`
**Функция сервера:** `POST /api/v1/sync/add-article`
**Исполнитель логики:** `src/services/sync.py` (метод `add_article`)
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Создает новый артикул (товарную позицию) и автоматически добавляет его во все связанные листы таблицы. Генерирует уникальный ID на основе префикса проекта и следующего порядкового номера. Гарантирует, что новый товар появится на всех листах, где он должен быть согласно правилам синхронизации.

**Ключевые особенности:**
- Работает для всех проектов (MT, SS, SK).
- Автоматическая генерация следующего артикула на основе максимального номера.
- Добавляет строку на основной лист (PRIMARY) и на все связанные листы по правилам.
- Синхронизирует новый артикул в Supabase (если настроено).

---

## ⚙️ Алгоритм работы

### Фаза 1: Определение артикула (GAS)
1. **Пользователь** нажимает кнопку "➕ Добавить артикул" в меню.
2. **GAS** определяет текущий проект и лист PRIMARY из конфигурации.
3. **GAS** отправляет запрос на сервер для создания артикула.

### Фаза 2: Генерация ID (Server)
4. **Server** определяет код проекта и его префикс (MT, SK, SS).
5. **Server** сканирует существующие артикулы на листе PRIMARY для определения максимального номера.
6. **Server** генерирует следующий по порядку артикул (например, если максимальный MT-0450, следующий будет MT-0451).

### Фаза 3: Добавление на листы (Server)
7. **Server** добавляет новую строку на основной лист с сгенерированным артикулом в колонке A.
8. **Server** загружает правила синхронизации для данной таблицы.
9. Для каждого правила, где `source_sheet` совпадает с основным листом:
    - Находит целевой лист.
    - Добавляет строку с тем же артикулом на целевой лист.
10. Если настроена синхронизация с Supabase, создается запись в базе.

### Фаза 4: Результат
11. **Server** возвращает: `{status, article, sheets_updated}`.
12. **GAS** показывает результат: "Артикул X добавлен на N листов".

## ⚠️ Важные замечания

- Артикул генерируется автоматически — пользователю не нужно вводить его вручную.
- Если лист PRIMARY не найден, операция завершится с ошибкой.
- Добавление артикула не заполняет остальные колонки — только ID в колонке A.
