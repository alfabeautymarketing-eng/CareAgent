# 🔄 Кнопка: Синхронизировать строку

**Файл:** `BUTTON_SYNC_ROW.md`
**Функция GAS:** `syncSelectedRow`
**Функция сервера:** `POST /api/v1/sync/event`
**Исполнитель логики:** `src/services/sync.py` (метод `sync_row` / `sync_row_async`)
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Синхронизирует одну или несколько выделенных строк в текущем листе по активным правилам. В отличие от "Синхронизировать всё", обрабатывает только выделенные пользователем строки, что значительно быстрее при точечных изменениях.

**Ключевые особенности:**
- Работает для всех проектов (MT, SS, SK).
- Требует предварительного выделения строк в Google Sheets.
- Поддерживает множественное выделение (несколько строк).
- Показывает подтверждение с количеством выбранных строк.
- Каждая строка обрабатывается по всем подходящим правилам.

---

## ⚙️ Алгоритм работы

### Фаза 1: Валидация выделения (GAS)
1. **Пользователь** выделяет строки в Google Sheets.
2. **Пользователь** нажимает кнопку "🔄 Синхронизировать строку" в меню.
3. **GAS** проверяет наличие активного выделения (`getActiveRange()`). Если ничего не выделено — показывает alert.
4. **GAS** проверяет, что выбраны строки с данными (не заголовок, строка > 1).
5. **GAS** показывает подтверждение: "Синхронизировать N строк(и) на листе X?"

### Фаза 2: Отправка на сервер (GAS -> Server)
6. Пользователь подтверждает (YES).
7. **GAS** показывает toast: "Синхронизация..."
8. Для каждой выделенной строки **GAS** собирает данные:
   - Имя листа (`sheet_name`)
   - Номер строки (`row_number`)
   - Ключ строки — значение из колонки A (артикул)
   - Код проекта
9. **GAS** отправляет запрос на сервер для каждой строки.

### Фаза 3: Обработка (Server)
10. **Server** загружает правила для данного `spreadsheet_id`.
11. **Server** фильтрует правила по листу-источнику.
12. Для каждого подходящего правила:
    - Определяет `source_header` и `target_header`.
    - Считывает значение из исходной ячейки.
    - Применяет правило: записывает значение в целевой лист/ячейку.
13. Если настроена синхронизация с Supabase, данные строки также обновляются в базе.

### Фаза 4: Результат
14. **Server** возвращает статистику: `{status, rules_applied, errors}`.
15. **GAS** показывает результат пользователю.

## ⚠️ Важные замечания

- Перед нажатием необходимо выделить строки с данными (не заголовок).
- Async-версия обрабатывает правила для строки параллельно (3-10x быстрее).
- Используется защита от циклов (cell locking) для предотвращения бесконечных каскадных обновлений.
