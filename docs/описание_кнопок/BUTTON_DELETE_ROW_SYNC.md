# ❌ Кнопка: Удалить строку с синхронизацией

**Файл:** `BUTTON_DELETE_ROW_SYNC.md`
**Функция GAS:** `deleteSelectedRowsWithSync`
**Функция сервера:** Логика выполняется на стороне GAS с серверным логированием
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Удаляет выделенные строки из текущего листа и автоматически удаляет соответствующие строки со всех связанных листов таблицы. В отличие от простого удаления строки в Google Sheets, эта функция гарантирует, что артикул будет удален везде, где он присутствует, чтобы не оставалось "осиротевших" записей.

**Ключевые особенности:**
- Работает для всех проектов (MT, SS, SK).
- Требует предварительного выделения строк.
- Каскадное удаление по всем связанным листам согласно конфигурации проекта.
- Запрашивает подтверждение перед удалением.
- Подробное логирование каждого шага удаления.

---

## ⚙️ Алгоритм работы

### Фаза 1: Валидация и подтверждение (GAS)
1. **Пользователь** выделяет строки для удаления в Google Sheets.
2. **Пользователь** нажимает кнопку "❌ Удалить строку с синхронизацией" в меню.
3. **GAS** проверяет наличие активного выделения. Если ничего не выделено — показывает alert.
4. **GAS** определяет текущий лист и конфигурацию проекта (`SHEETS`).

### Фаза 2: Сбор артикулов (GAS)
5. **GAS** собирает артикулы (колонка A) из всех выделенных строк.
6. **GAS** показывает подтверждение с перечислением артикулов для удаления.

### Фаза 3: Каскадное удаление (GAS)
7. Для каждого связанного листа из конфигурации проекта:
    - Открывает лист.
    - Ищет строки с совпадающим артикулом в колонке A.
    - Удаляет найденные строки (в обратном порядке, чтобы не сбить индексы).
8. Удаляет строки с текущего листа.
9. Логирует каждый шаг на сервер.

### Фаза 4: Результат
10. **GAS** показывает toast с результатом: сколько строк удалено и с каких листов.
11. Все операции логируются через серверный endpoint.

## ⚠️ Важные замечания

- **Операция необратима!** Удаленные строки нельзя восстановить (кроме истории версий Google Sheets).
- Удаление происходит на ВСЕХ связанных листах — убедитесь, что выбраны правильные строки.
- Строки удаляются в обратном порядке для корректности индексов.
- Рекомендуется сначала проверить, какие листы связаны, через "Настройка правил синхронизации".
