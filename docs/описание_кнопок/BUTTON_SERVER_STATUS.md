# 🔍 Кнопка: Проверить статус сервера

**Файл:** `BUTTON_SERVER_STATUS.md`
**Функция GAS:** `showAllServicesStatus_proxy`
**Функция сервера:** `GET /api/v1/health` / `GET /api/v1/status`
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Проверяет доступность и состояние всех сервисов AgentCare: основного сервера, подключения к Google Sheets API, Supabase и других компонентов. Показывает сводную информацию о здоровье системы, помогая быстро диагностировать проблемы.

**Ключевые особенности:**
- Проверка доступности основного сервера (FastAPI).
- Проверка подключения к Google Sheets API.
- Проверка подключения к Supabase.
- Отображение версии сервера и времени работы (uptime).
- Показ текущего SERVER_URL (Production VPS или ngrok-туннель).

---

## ⚙️ Алгоритм работы

### Фаза 1: Отправка запроса (GAS)
1. **Пользователь** нажимает кнопку "🔍 Проверить статус сервера" в меню.
2. **GAS** вызывает `showAllServicesStatus_proxy`.
3. **GAS** отправляет `GET` запрос на `{SERVER_URL}/api/v1/health`.

### Фаза 2: Диагностика (Server)
4. **Server** проверяет каждый компонент:
   - **API Server**: Отвечает ли FastAPI (всегда OK, если запрос дошел).
   - **Google Sheets API**: Попытка доступа к API (валидность сервисного аккаунта).
   - **Supabase**: Пинг к базе данных Supabase.
   - **Rules Engine**: Наличие файлов правил синхронизации.
5. **Server** собирает статус каждого компонента и общий статус.

### Фаза 3: Отображение (GAS)
6. **GAS** получает ответ и форматирует информацию.
7. **GAS** показывает alert или sidebar со сводкой:
   - Статус каждого сервиса (OK / ERROR).
   - Текущий SERVER_URL.
   - Время ответа.
   - Версия сервера.

## ⚠️ Важные замечания

- Если сервер недоступен, GAS покажет ошибку подключения.
- Проверьте SERVER_URL (через кнопку "ℹ️ Показать текущий SERVER_URL"), если статус недоступен.
- При использовании ngrok-туннеля URL может меняться — убедитесь, что он актуален.
