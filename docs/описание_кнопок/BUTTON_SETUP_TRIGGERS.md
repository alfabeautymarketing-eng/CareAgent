# 🔧 Кнопка: Обновить триггеры

**Файл:** `BUTTON_SETUP_TRIGGERS.md`
**Функция GAS:** `setupTriggers` / `setupTriggers_proxy`
**Функция сервера:** Логика выполняется на стороне GAS (Google Apps Script Triggers API)
**Расположение в меню:** ⚙️ Настройка > 🔄 Синхронизация

---

## 📝 Описание

Устанавливает (или обновляет) триггеры Google Apps Script, необходимые для автоматической работы системы синхронизации. Триггеры обеспечивают автоматический вызов серверных функций при редактировании ячеек и изменении структуры таблицы.

**Ключевые особенности:**
- Создает триггер `onEdit` для автоматической синхронизации при изменении ячеек.
- Создает триггер `onChange` для отслеживания структурных изменений (добавление/удаление строк/листов).
- Проверяет, есть ли уже установленные триггеры, и не создает дубликаты.
- Работает для всех проектов (MT, SS, SK).

---

## ⚙️ Алгоритм работы

### Фаза 1: Проверка существующих триггеров (GAS)
1. **Пользователь** нажимает кнопку "🔧 Обновить триггеры" в меню.
2. **GAS** получает список всех существующих триггеров проекта через `ScriptApp.getProjectTriggers()`.
3. **GAS** проверяет, есть ли среди них триггеры для:
   - `handleOnEdit` (обработка редактирования)
   - `handleOnChange` (обработка изменений структуры)

### Фаза 2: Создание триггеров (GAS)
4. Если триггер `handleOnEdit` не найден:
   - Создается новый триггер: `ScriptApp.newTrigger('handleOnEdit').forSpreadsheet(ss).onEdit().create()`.
5. Если триггер `handleOnChange` не найден:
   - Создается новый триггер: `ScriptApp.newTrigger('handleOnChange').forSpreadsheet(ss).onChange().create()`.

### Фаза 3: Результат
6. **GAS** показывает alert с результатом:
   - Какие триггеры были созданы.
   - Какие уже существовали.

## ⚠️ Важные замечания

- Для установки триггеров нужны права владельца или редактора таблицы.
- Триггеры устанавливаются один раз. Повторный запуск не создаст дубликатов.
- Без установленных триггеров автоматическая синхронизация (по `onEdit`) работать не будет.
- Если триггеры "сломались" (например, после смены аккаунта), нажмите эту кнопку для переустановки.
