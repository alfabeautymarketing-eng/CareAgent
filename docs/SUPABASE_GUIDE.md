# 🗄️ Инструкция по использованию Supabase в Google Sheets

В меню "Ecosystem" добавлен раздел **🗄️ Supabase**, который предоставляет прямой доступ к вашей базе данных через интерфейс Google Таблиц.

## 🛠 Предварительная настройка

Для работы функций убедитесь, что ваш Python-сервер запущен и настроен:

1. Откройте файл `.env` в папке проекта.
2. Добавьте/обновите ключи подключения:
   ```bash
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SERVICE_KEY=your_service_role_secret
   ```
3. Перезапустите сервер: `make run` или `make dev`.

---

## 🚀 Доступные функции

### 1. 📋 View Tables (Просмотр таблиц)
**Функция:** `showSupabaseTablesView`
- **Что делает:** Показывает список всех доступных таблиц в вашей базе данных Supabase.
- **Как использовать:**
  1. Нажмите "View Tables".
  2. Появится диалоговое окно со списком (например: `users`, `products`, `orders`).
- **Примечание:** Если список пуст, проверьте права доступа или наличие таблиц в схеме `public`.

### 2. ⚡ Execute SQL (Выполнить SQL)
**Функция:** `executeSupabaseSqlQuery`
- **Что делает:** Выполняет SQL-запрос `SELECT` и показывает результаты в виде таблицы.
- **Синтаксис:** Поддерживаются простые запросы вида:
  ```sql
  SELECT * FROM products LIMIT 10
  ```
- **Как использовать:**
  1. Нажмите "Execute SQL".
  2. Введите запрос в появившееся поле.
  3. Результат откроется в новом окне.
- **Ограничения:** В целях безопасности в данной версии поддерживаются только `SELECT` запросы (чтение данных). `INSERT`, `UPDATE`, `DELETE` отключены.

### 3. 📥 Import Data (Импорт данных)
**Функция:** `importSupabaseData`
- **Что делает:** Загружает данные из выбранной таблицы Supabase прямо на активный лист Google Sheet.
- **Внимание:** Текущий лист будет очищен перед вставкой!
- **Как использовать:**
  1. Создайте новый пустой лист (рекомендуется) или перейдите на тот, который можно перезаписать.
  2. Нажмите "Import Data".
  3. Введите название таблицы (например, `products`) и нажмите OK.
  4. Данные (первые 100 строк) загрузятся с заголовками.

### 4. 📤 Export Data (Экспорт данных)
**Функция:** `exportSupabaseData`
- **Статус:** 🔒 Read-only (Безопасный режим)
- **Описание:** Функция предназначена для отправки данных из таблицы в Supabase.
- **Примечание:** В текущей версии функция работает в режиме защиты данных и требует явного подтверждения структуры таблицы на сервере перед записью. Это предотвращает случайную потерю данных в БД.

### 5. 🚀 Open Console (Консоль)
- Открывает веб-интерфейс Supabase в браузере для полного управления базой данных.

## 🔧 Возможные ошибки

- **Ошибка "SERVER_URL not set":** Серверный URL не прописан в скриптах. Попробуйте перезагрузить таблицу или запустите функцию `handleOnOpen` вручную.
- **Ошибка 503 "Supabase not configured":** Вы не добавили ключи `SUPABASE_URL` и `SUPABASE_SERVICE_KEY` в `.env` файл сервера.
- **"Import returned no data":** Таблица пустая или имя введено неверно (учитывайте регистр).

По всем вопросам обращайтесь к администратору (AI Agent).
