## 🏗 Подготовка
Перед началом миграции убедитесь, что у вас есть доступ к:
- Репозиторию AgentCare (GitHub/GitLab)
- Файлу `.env` (или его значениям)
- Файлу `config/credentials.json` (Service Account)
- API ключу Gemini AI
- Учетным данным Supabase/PostgreSQL

---

## 🚀 Пошаговая настройка

### 1. Клонирование репозитория
```bash
git clone <url-репозитория> ~/Desktop/AgentCare
cd ~/Desktop/AgentCare
```

### 2. Конфигурация
Создайте файл `.env` из шаблона:
```bash
cp .env.template .env
```
Отредактируйте `.env`, указав все необходимые ключи и ID таблиц.

### 3. Запуск автоматической настройки
Мы создали скрипт, который выполнит 9 фаз настройки за вас:
```bash
bash setup_new_mac.sh
```
Скрипт проверит зависимости, установит Python, настроит Docker и запустит сервисы.

## 💾 Перенос данных
Все важные данные AgentCare хранятся в следующих местах:
1. **Google Sheets**: Облако (перенос не требуется)
2. **Redis**: Кэш (временные данные, можно пересоздать)
3. **Supabase**: Облако (перенос не требуется)
4. **Локальные логи**: Папки `data/sync_logs`, `data/function_logs`.

Если вам нужны прошлые логи, скопируйте папку `data/` со старого устройства.

## 🛠 Устранение неполадок

### Ошибка: "Google API connection failed"
- Проверьте наличие `config/credentials.json`
- Убедитесь, что сервисный аккаунт имеет доступ к таблицам (права "Редактор")
- Проверьте ID таблиц в `.env`

### Ошибка: "Docker fails to start"
- Убедитесь, что Docker Desktop запущен
- Проверьте доступную память (минимум 4GB выделено Docker)

### Ошибка: "Timeout in price processing"
- Проверьте соединение с интернетом
- Проверьте логи сервера: `docker-compose logs -f agentcare`

## 🔄 Сценарии восстановления
Если система перестала отвечать:
1. Выполните проверку здоровья: `python scripts/health_check.py`
2. Перезапустите контейнеры: `docker-compose restart`
3. Если не помогло, пересоберите: `docker-compose up -d --build`
