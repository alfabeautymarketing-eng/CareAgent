# Центр Управления для AI Агентов

**Дата создания:** 2026-01-07  
**Цель:** Обеспечить единый источник правды для всех AI агентов

---

## 🎯 Единый Источник Задач: Beads

### КРИТИЧЕСКИЕ ПРАВИЛА

1. **ТОЛЬКО BEADS** - единственный источник задач для ВСЕХ агентов
2. **ЗАПРЕТ на локальные task.md** в артефактах (они только для заметок)
3. **ОБЯЗАТЕЛЬНЫЙ старт** каждой сессии с `bd ready --no-db --readonly`
4. **ВСЕГДА СПРАШИВАЙ** - если что-то непонятно, задавай уточняющие вопросы. Лучше переспросить, чем ошибиться!

---

## 📋 Рабочий Процесс

### Начало Работы (КАЖДАЯ сессия)

```bash
# Шаг 1: Проверить доступные задачи
bd ready --no-db --readonly

# Если bd не найден:
/Users/aleksandr/.local/bin/bd ready --no-db --readonly
```

### Если Beads в READ-ONLY режиме

**ЧТО ДЕЛАТЬ АГЕНТУ:**

1. ✅ Показать пользователю список задач из `bd ready`
2. ✅ Сказать на русском:
   
   > "Beads находится в режиме только для чтения. Пожалуйста, создайте задачу (`bd create '<описание>'`) или укажите ID существующей задачи из списка выше (например: AgentCare-563)."

3. ✅ **ДОЖДАТЬСЯ** ответа пользователя
4. ✅ Продолжить работу ТОЛЬКО после получения ID

**ЧТО ДЕЛАТЬ ПОЛЬЗОВАТЕЛЮ:**

```bash
# Вариант 1: Создать новую задачу
bd create "Описание задачи"

# Вариант 2: Использовать существующую
# Указать агенту ID (например: AgentCare-563)
```

### Назначение Задачи

```bash
# После получения ID
bd pin AgentCare-563

# Проверить статус
bd status
```

### Завершение Работы

```bash
# Если есть права записи
bd sync

# Если нет - сообщить пользователю:
# "Пожалуйста, выполните `bd sync` для синхронизации изменений"
```

## 🚫 Частые Ошибки

### ❌ НЕПРАВИЛЬНО
- Создавать `task.md` в артефактах и работать по нему
- Говорить "у меня нет активных задач" без проверки `bd ready`
- Начинать работу без привязки к Beads Issue ID

### ✅ ПРАВИЛЬНО
- Всегда начинать с `bd ready --no-db --readonly`
- Спрашивать пользователя об ID задачи, если Beads read-only
- Указывать Issue ID во всех коммитах (`fix: AgentCare-563 - описание`)
