# Структура меню AgentCare (версия 2.0)

## 📋 Обзор

Меню переструктурировано на основе **жизненного цикла пользователя** - реального workflow обработки заказов от производителя до доставки.

**Ключевой принцип:** Каждый пункт меню - это **одна функция, одна кнопка**.

---

## 🔄 Жизненный цикл пользователя

### Этап 1: 🏷️ Прайс-лист
Получение листов от производителя, обновление актуальных данных

```
1. 📥 Загрузить и обработать прайс
   └─ serverProcessPrimaryData (интегрирует MAIN/TESTER/SAMPLES/PROBES)

2. 📊 Загрузить остатки
   └─ serverLoadStockData

3. [separator]

4. 💰 Анализировать цены
   └─ menuAnalyzePrices (новая функция для анализа)

5. ✅ Сформировать свежий прайс
   └─ serverGenerateFreshPriceList (новая функция)
```

**Что происходит:**
- Загрузка прайс-листа из Excel
- Парсинг данных по проекту (MT/SK/SS)
- Загрузка остатков из источника
- Анализ изменения цен
- Создание свежего прайса с актуальными ценами

**Поток данных:** Производитель → Excel → AgentCare → Google Sheets

---

### Этап 2: 🛒 Заказ & Документация
Подготовка к продаже, таможня, сертификация

```
1. 📋 Подготовить заказ
   └─ serverPrepareOrder (подготовка заказа к обработке)

2. [separator]

3. 📦 Подготовить документы для таможни
   └─ serverPrepareCustomsDocuments (сбор документов ДС)

4. ✏️ Заполнить разрешительную документацию
   └─ serverFillPermitDocumentation (наполнение разрешений)

5. [separator]

6. 🔬 Сертификация (главный workbench)
   └─ serverCertificationWorkbench

7. 📄 Лист новинки
   └─ serverCreateNewsSheet

8. 📋 Протоколы (353пп)
   └─ serverGenerateProtocols353pp

9. 📋 ДС Макеты (353пп)
   └─ serverGenerateDsLayouts

10. 📦 Собрать документы для заявки
    └─ structureDocuments_353pp

11. [separator]

12. 🥃 Спирты - Посчитать
    └─ serverCalculateSpiritNumbers

13. 🥃 Спирты - Создать Макеты
    └─ generateSpiritProtocols

14. 🔄 Спирты - Пересчитать каскады
    └─ serverRecalculateCascades
```

**Что происходит:**
- Подготовка заказа для отправки
- Сбор всех необходимых документов для таможни (ДС, ОТТДЛ и т.д.)
- Заполнение разрешительной документации (сертификаты, допуски)
- Создание протоколов для сертификации (353пп)
- Специальная обработка спиртосодержащей продукции

**Поток данных:** Google Sheets → Документы → Таможня → Сертификация

---

### Этап 3: 📦 Экспорт & Выгрузка

**Что происходит:**
- Экспорт специальных данных (акции, наборы)
- Форматирование листов
- Создание инвойса
- Сбор финального пакета документов

**Поток данных:** Google Sheets → Экспорт → PDF/Excel → Клиент

## 🎯 Принципы дизайна

### 1. Одна кнопка = одна функция
Каждый пункт меню запускает **одну** функцию без диалогов выбора.

Пример ✅:
```
📥 Загрузить и обработать прайс
└─ serverProcessPrimaryData (умеет определить mode сам)
```

Пример ❌:
```
Загрузить прайс (диалог выбора mode: MAIN/TESTER/SAMPLES)
└─ требует доп. взаимодействия
```

### 2. Иерархия по жизненному циклу
Меню отражает реальный workflow пользователя:
1. Загрузка данных
2. Подготовка документов
3. Выгрузка результатов
4. Аналитика (доп.)
5. Управление (настройки)

### 3. Разделители для группировки
Используются `separator: True` для логической группировки функций внутри одного меню.

### 4. Подменю только для Настроек
Подменю (submenu) используются только для блока Настроек, чтобы не усложнять главное меню.

## 🔄 Миграция с старой структуры

### Было (v1.0):
Основные меню:
- 📦 Выгрузка
- 🚚 Поставка
- 🔬 Сертификация
- ⚙️ Синхронизация (смешанное меню)
- 🤖 Агент
- 📋 Логи
- 🗄️ Supabase

**Проблемы:**
- Не отражал бизнес-цикл пользователя
- Синхронизация была混в главном меню
- Управление разбросано по разным местам

### Стало (v2.0):
Основные меню:
- 🏷️ Прайс-лист (**новое, главное, этап 1**)
- 🛒 Заказ & Документация (объединено из Поставки + Сертификации, этап 2)
- 📦 Экспорт & Выгрузка (переименовано, этап 3)
- 🤖 AI Агент (остаётся, дополнительно)

Управление объединено:
- ⚙️ Настройки (объединено в одно меню с подменю)
  - 🔄 Синхронизация
  - 📋 Логи
  - 🗄️ Supabase
  - 🟢 Ecosystem

**Преимущества:**
- Отражает реальный жизненный цикл пользователя
- Одна кнопка = одна функция (без диалогов выбора)
- Управление спрятано в подменю ⚙️ Настройки
- Чистое, интуитивное главное меню

## 🚀 Новые функции (заглушки)

При реализации меню добавлены "заглушки" функций которых нет в коде:

1. **serverProcessPrimaryData** - должна интегрировать MAIN/TESTER/SAMPLES/PROBES
2. **serverLoadStockData** - загрузка остатков
3. **menuAnalyzePrices** - анализ изменения цен
4. **serverGenerateFreshPriceList** - генерация свежего прайса
5. **serverPrepareOrder** - подготовка заказа
6. **serverPrepareCustomsDocuments** - подготовка таможных документов
7. **serverFillPermitDocumentation** - заполнение разрешительных документов
8. **serverCertificationWorkbench** - главный workbench сертификации

Эти функции должны быть реализованы в GAS коде.
