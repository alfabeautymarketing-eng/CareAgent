# Правила синхронизации (server-side)

## Ключевая идея
Чтобы ускорить синхронизацию и не читать лист «Правила синхро» при каждом событии, правила можно хранить на сервере. Если присутствует файл `config/rules/<spreadsheet_id>.yaml`, сервис берёт правила из него и не запрашивает лист до истечения TTL.

## Формат `config/rules/<spreadsheet_id>.yaml`

Массив правил:
```yaml
- id: rule_001
  enabled: true
  category: Сертификация
  hashtags: "#sync"
  source_sheet: Главная
  source_header: Примечание/записная книжка
  target_sheet: Сертификация
  target_header: Примечание/записная книжка
  is_external: false
  target_doc_id: ""   # опционально, только если is_external=true
- id: rule_002
  enabled: true
  category: Прайс
  hashtags: ""
  source_sheet: Главная
  source_header: Код в 1С
  target_sheet: Расчет цены
  target_header: Код в 1С
  is_external: false
```

Имена правил генерируются автоматически при сохранении: `<NNN>-<SRC>-<TGT>(<Header>)`, где `NNN` — порядковый номер, `SRC`/`TGT` — буквы листов (Г, С, Э, З, Д, Р, П, А и т.д.), `Header` — имя столбца.

Обязательные поля для активного правила: `source_sheet`, `source_header`, `target_sheet`, `target_header`. Для внешних правил (`is_external: true`) нужен `target_doc_id`. Поле `hashtags` более не используется (при загрузке игнорируется).

## Приоритет загрузки
1. Если есть `config/rules/<spreadsheet_id>.yaml` и в нём есть активные правила — используются они.
2. Иначе правила читаются из листа «Правила синхро» (кэш 5 минут).

## Обновление правил
- Чтобы обновить правила, измените YAML и перезапустите сервис (или подождите 5 минут до истечения кэша/вызовите `force_reload` через код). Можно использовать HTML-форму `docs/rules-form.html`, которая читает/пишет через API `/rules/{spreadsheet_id}`.

## Исключения
- События на листах `Логи` и `Журнал синхро` игнорируются, чтобы не тратить квоту и время на служебные изменения.
