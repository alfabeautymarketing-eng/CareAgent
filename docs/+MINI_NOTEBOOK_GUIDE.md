# 📘 Mini-NotebookLM: Руководство пользователя

В этом руководстве описано, как эффективно использовать инструмент **Mini-NotebookLM** (`scripts/mini_notebook.py`), встроенный в ваш проект AgentCare.

Этот инструмент позволяет вам "разговаривать" с кодом и документацией вашего проекта, используя мощную модель Gemini 1.5 Pro/Flash, аналогично тому, как работает Google NotebookLM, но с полным контролем и доступом к актуальным файлам.

---

## 🚀 Быстрый старт

Инструмент запускается из терминала в корне проекта.

**1. Задать один вопрос по стандартным файлам (`AI_RULES.md`, `README.md`, etc.):**
```bash
python3 scripts/mini_notebook.py "Какие главные правила Beads?"
```

**2. Интерактивный режим (Чат):**
```bash
python3 scripts/mini_notebook.py -i
```

**3. Анализ конкретных файлов (Chat w/ Code):**
```bash
python3 scripts/mini_notebook.py "Как работает логирование?" --files src/services/logging.py
```

## 🛠 Сценарии использования (Use Cases)

### 1. 🎓 Онбординг и Вспоминание
*Когда вы забыли, как реализована определенная фича или какие правила действуют.*

**Пример:**
> "Как у нас настроена миграция с Google Apps Script на Python?"

**Команда:**
```bash
python3 scripts/mini_notebook.py "Как реализована миграция?" -f AI_RULES.md AGENTS.md
```

### 2. 🐛 Умная Отладка (AI Debugging)
*Анализ логов и поиск причин ошибок. Вы можете "скормить" инструменту последние логи и код, который мог вызвать ошибку.*

**Пример:**
> "Посмотри на ошибку в логах и код сервиса. Почему падает синхронизация?"

**Команда (используя glob-паттерны):**
```bash
# Представим, что у вас есть файл logs/error.log
python3 scripts/mini_notebook.py "Проанализируй ошибку и предложи фикс" -f logs/app.log src/services/sync.py
```

### 3. 🔍 Аудит Кода и Compliance
*Проверка, соответствует ли новый код архитектурным принципам.*

**Пример:**
> "Действуй как Staff Engineer. Проверь этот файл на соответствие принципу Server-First и правилам типизации."

**Команда:**
```bash
python3 scripts/mini_notebook.py "Проведи ревью этого файла" -f src/new_feature.py AI_RULES.md
```

### 4. 📝 Генерация Документации
*Автоматическое создание описания для новых модулей.*

**Пример:**
> "Напиши README.md для этого модуля, опиши его классы и методы."

**Команда:**
```bash
python3 scripts/mini_notebook.py "Сгенерируй документацию в формате Markdown" -f src/services/price_processor.py
```

### 5. 🏗 Планирование Рефакторинга
*Оценка влияния изменений на другие части системы.*

**Пример:**
> "Я хочу изменить класс `GeminiClient`. Какие файлы зависят от него и что нужно учесть?"

**Команда:**
```bash
python3 scripts/mini_notebook.py "Анализ зависимостей" -f src/**/*.py
```
*(Примечание: Используйте с осторожностью на очень больших проектах, чтобы не превысить лимит токенов, хотя Gemini 1.5 переварит почти весь этот проект целиком).*

## 💡 Полезные Советы

1.  **Glob-паттерны:**
    Скрипт понимает звездочки `*`.
    *   `src/services/*.py` - все сервисы.
    *   `**/*.md` - вся документация в проекте (рекурсивно).

2.  **Ограничение контекста:**
    Скрипт автоматически пропускает файлы больше 100 КБ, чтобы не забивать контекст мусором.

3.  **Температура:**
    В скрипте выставлена температура `0.2`. Это делает ответы очень точными и основанными на фактах. Если вам нужно что-то более творческое (например, "Придумай идею для новой фичи"), можно временно поменять это в коде скрипта (`scripts/mini_notebook.py`).

4.  **Секреты:**
    Инструмент использует `GEMINI_API_KEY` из вашего `.env`. Убедитесь, что он там есть.

## ❓ FAQ

**В: Чем это лучше ChatGPT/Claude web UI?**
О: Тем, что контекст собирается **автоматически** из ваших локальных файлов. Вам не нужно копи-пастить код в браузер. Плюс, используется Gemini 1.5 с огромным окном контекста.

**В: Можно ли загрузить PDF?**
О: В текущей версии скрипт читает текстовые файлы (код, md, logs, json). Для PDF нужна небольшая доработка (интеграция `PyMuPDF`), но базово он ориентирован на text-based project files.

**В: Куда сохраняются ответы?**
О: Ответы выводятся в консоль. Вы можете перенаправить их в файл:
`python3 scripts/mini_notebook.py "Вопрос" > answer.md`
