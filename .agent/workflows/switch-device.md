---
description: Рабочий процесс переключения между устройствами (Switch Device)
---

Этот воркфлоу описывает шаги, которые необходимо выполнить при переходе с одного макбука на другой, чтобы код и контекст ИИ всегда оставались актуальными.

## 1. Завершение работы на устройстве А

Перед тем как закрыть крышку текущего макбука:

1. Выполните команду:
   ```bash
   bash git-autosave.sh
   ```
   *Это синхронизирует задачи Beads, сделает `git commit` с текущим временем и `git push` в репозиторий.*

## 2. Начало работы на устройстве Б

Когда вы открываете проект на другом макбуке:

1. Выполните команду:
   ```bash
   bash git-load.sh
   ```
   *Это подтянет изменения из Git (`pull`), обновит зависимости Python и синхронизирует состояние Beads.*

2. Убедитесь, что Antigravity видит актуальные задачи:
   ```bash
   bd ready
   ```

## Примечание для ИИ-агентов
Если пользователь говорит "я пересел за другой ноут" или "давай синхронизируемся", агент ОБЯЗАН предложить выполнить `git-load.sh` или запустить его самостоятельно (если это безопасно).
