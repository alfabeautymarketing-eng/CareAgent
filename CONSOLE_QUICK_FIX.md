# 🔧 КАК ОТКРЫТЬ CONSOLE - ПОШАГОВО

## ⚠️ ПРОБЛЕМА:
Не получается открыть Console в Google Sheets

## ✅ РЕШЕНИЕ:

---

## СПОСОБ 1️⃣: Через меню Extensions (РЕКОМЕНДУЕТСЯ)

### Шаг 1: Откройте Google Sheets
Откройте вашу таблицу в браузере (например, Montibello)

**Экран должен выглядеть так:**
```
┌──────────────────────────────────────────────┐
│ Google Sheets - Montibello                    │
├──────────────────────────────────────────────┤
│ File  Edit  View  Insert  Format  Data ...   │
│                                              │
│ [Таблица с данными]                         │
└──────────────────────────────────────────────┘
```

### Шаг 2: НЕ НАЖИМАЙТЕ на Extensions в главном меню Sheets!

⚠️ **ВНИМАНИЕ:** Есть Extensions в главном меню Google Sheets - это НЕ ТО!

Вместо этого ищите в **верхнем меню** вашей таблицы:

```
┌──────────────────────────────────────────────┐
│ File  Edit  View  Insert  Format  Data  Tools │
│                                              │
│ ← КЛИКАЙТЕ НА "Tools" (или "Инструменты")   │
└──────────────────────────────────────────────┘
```

**Для Mac/Windows:** В верхней части экрана найдите меню, где видны:
- File
- Edit
- View
- Insert
- Format
- Data
- Tools ← **КЛИКАЙТЕ ЗДЕСЬ**

### Шаг 3: После клика на Tools откроется меню

```
┌──────────────────────┐
│ Tools (меню)         │
├──────────────────────┤
│ ✓ Protection        │
│   Script editor     │ ← КЛИКАЙТЕ ЗДЕСЬ
│   Macros            │
│   ...               │
└──────────────────────┘
```

**ИЛИ ищите:**
- "Script editor"
- "Редактор скриптов"
- "Apps Script"

### Шаг 4: Откроется новая вкладка с редактором

Ждите 3-5 секунд, должна открыться новая вкладка браузера.

**Экран редактора:**
```
┌──────────────────────────────────────────────┐
│ Apps Script                                   │
├──────────────────────────────────────────────┤
│ File  Edit  View  Run  Debug                 │
├──────────────────────────────────────────────┤
│                                              │
│ // Код скриптов здесь                       │
│ function createAgentMenu() {                 │
│   ...                                        │
│ }                                            │
│                                              │
│                                              │
│ [внизу экрана пусто]                        │
└──────────────────────────────────────────────┘
```

### Шаг 5: Откройте Console

**ВАЖНО:** Нажмите одновременно: **Ctrl + Enter**

(На Mac может быть: Cmd + Enter, но попробуйте Ctrl + Enter)

### Шаг 6: Console должна появиться внизу!

**Должно выглядеть так:**
```
┌──────────────────────────────────────────────┐
│ Apps Script                                   │
├──────────────────────────────────────────────┤
│ File  Edit  View  Run  Debug                 │
│ // Код скриптов                             │
│ function createAgentMenu() {                 │
│   ...                                        │
│ }                                            │
├──────────────────────────────────────────────┤
│ 📋 Execution log  / Logs / Stackdriver       │ ← ПОЯВИЛАСЬ
│ >_ (мигающий курсор здесь)                  │
└──────────────────────────────────────────────┘
```

✅ **ГОТОВО! Console открыта!**

## СПОСОБ 2️⃣: Если не получилось через меню

### Вариант A: Используйте клавиатурный ярлык

Когда в Google Sheets таблица открыта, попробуйте:

```
Mac:     Cmd + Alt + N
Windows: Ctrl + Alt + N
```

Откроется редактор в новой вкладке.

Потом нажмите **Ctrl + Enter** чтобы открыть Console.

### Вариант B: Найдите меню Extensions

В Google Sheets (НЕ в редакторе!) найдите в верхнем меню:

```
Меню Google Sheets
┌─────────────────────────┐
│ File                    │
│ Edit                    │
│ View                    │
│ Insert                  │
│ Format                  │
│ Data                    │
│ Tools                   │
│ Extensions        ← ТУТ │
└─────────────────────────┘
```

Кликните **Extensions** → **Apps Script**

## 🔴 ЕСЛИ НИЧЕГО НЕ РАБОТАЕТ:

### Проверка 1: Правильная таблица?

**Убедитесь что вы в одной из этих таблиц:**

```
✅ MT (CosmeticaBar / Montibello)
✅ SK (Carmado)
✅ SS (San)
```

Если это временная или другая таблица - не будет работать!

### Проверка 2: Правильный браузер?

Apps Script работает в:
- ✅ Chrome (рекомендуется)
- ✅ Firefox
- ✅ Safari
- ✅ Edge

### Проверка 3: Может быть синий кнопка?

После открытия редактора, посмотрите в верхнюю правую часть окна:

```
┌────────────────────────────────────┐
│ ... | Debug | ▶ Run | ⚙ Deploy    │
└────────────────────────────────────┘
```

Если видите кнопку **Debug**, кликните её!

```
Откроется меню:
├─ New function
├─ Deploy
└─ View logs
```

Выберите **View logs** - откроется Console (же самое).

## ✅ КОГДА CONSOLE ОТКРЫТА

### Как выглядит готовая Console:

```
┌──────────────────────────────────────────────┐
│ Execution log    /  Logs  /  Stackdriver     │
│                                              │
│ [пусто, если первый раз]                    │
│                                              │
│ > _                                         │ ← сюда вводите команды
│                                              │
└──────────────────────────────────────────────┘
```

### Как вводить команды:

1. Кликните в поле **> _**
2. Скопируйте: `clearMenuCache();`
3. Вставьте в Console
4. Нажмите **Enter**

**Должно появиться:**
```
> clearMenuCache();
Меню кэша очищен!
```

Потом введите вторую команду:
```
> refreshMenu();
Меню обновлено!
```

## 🎥 ВИДЕО-ОПИСАНИЕ ШАГОВ

### Шаг 1: Откройте Sheets таблицу
```
1. Откройте браузер
2. Перейдите на Google Sheets (Montibello, Carmado или San)
3. Вы видите таблицу с данными
```

### Шаг 2: Найдите меню
```
1. В верхнем меню найдите "Tools"
2. Это одна из кнопок рядом с File, Edit, View, Insert, Format, Data
3. Кликните "Tools"
```

### Шаг 3: Выберите Script Editor
```
1. Из меню Tools выберите "Script editor"
2. Откроется новая вкладка браузера
3. Дождитесь загрузки (может быть 3-5 секунд)
```

### Шаг 4: Откройте Console
```
1. Нажмите одновременно Ctrl + Enter
2. Внизу экрана появится "Execution log"
3. Видите ">" с мигающим курсором?
4. Console готова!
```

### Шаг 5: Введите команды
```
1. Кликните в поле Console (где мигает курсор)
2. Скопируйте команду: clearMenuCache();
3. Вставьте (Ctrl+V)
4. Нажмите Enter
5. Повторите для refreshMenu();
```
