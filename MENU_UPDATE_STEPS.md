# 🎯 Пошаговая инструкция обновления меню

## ❌ ПРОБЛЕМА:
Вы видите старое меню в Google Sheets

## ✅ РЕШЕНИЕ:
Выполните эти шаги для КАЖДОГО проекта (MT, Carmado, San)

---

## ШАГИ:

### ШАГ 1️⃣: Откройте Google Sheets таблицу
Откройте любую таблицу проекта в браузере (например, Montibello)

---

### ШАГ 2️⃣: Откройте Apps Script редактор

**В верхнем меню таблицы найдите:**
```
Extensions → Apps Script
```

Или нажмите эту комбинацию:
```
Mac: Ctrl+Alt+N
Windows: Ctrl+Alt+N
```

✅ **Откроется новая вкладка** с редактором кода

---

### ШАГ 3️⃣: Откройте Console

**В редакторе нажмите:**
```
Ctrl+Enter
```

✅ **Снизу редактора откроется панель "Execution log"** с Console

---

### ШАГ 4️⃣: Скопируйте и выполните команду

**В поле Console (внизу) скопируйте эту строку:**

```javascript
clearMenuCache();
```

**Как это выглядит:**
```
Execution log
> clearMenuCache();
```

Нажмите **Enter**

✅ **Должно появиться:**
```
Меню кэша очищен!
```

---

### ШАГ 5️⃣: Вторая команда

**В тот же Console скопируйте:**

```javascript
refreshMenu();
```

Нажмите **Enter**

✅ **Должно появиться:**
```
Меню обновлено!
```

---

### ШАГ 6️⃣: Закройте редактор и обновите таблицу

**Закройте вкладку редактора** (или нажмите назад)

**На вкладке Google Sheets:**
- Обновите страницу: **Ctrl+R** (или F5)
- Или просто перезагрузитесь

✅ **Готово!** Откройте меню - должно быть новое! 🎉

---

## 📸 ВИЗУАЛЬНАЯ ИНСТРУКЦИЯ

### 1. Extensions → Apps Script
```
Google Sheets меню
├─ File
├─ Edit
├─ View
├─ Insert
├─ Format
├─ Data
├─ Tools
├─ Extensions ← КЛИКАЙТЕ ЗДЕСЬ
│  └─ Apps Script ← ВЫБИРАЙТЕ ЭТО
```

### 2. Откроется редактор
```
┌─────────────────────────────────┐
│ Apps Script редактор            │
├─────────────────────────────────┤
│ // Код скриптов                 │
│ function createAgentMenu() {    │
│   ...                           │
└─────────────────────────────────┘
```

### 3. Нажмите Ctrl+Enter
```
┌─────────────────────────────────┐
│ Apps Script редактор            │
├─────────────────────────────────┤
│ // Код скриптов                 │
│ function createAgentMenu() {    │
├─────────────────────────────────┤
│ Console / Logs / Stackdriver    │ ← ОТКРОЕТСЯ
│ > _                             │
└─────────────────────────────────┘
```

### 4. Введите команду в Console
```
Console / Logs / Stackdriver
> clearMenuCache();
```

Нажмите **Enter**

### 5. Введите вторую команду
```
Console / Logs / Stackdriver
> clearMenuCache();
> refreshMenu();
```

Нажмите **Enter**

## ⚠️ ЕСЛИ НЕ РАБОТАЕТ:

### Попробуйте вместо двух команд сразу запустить одну:

```javascript
PropertiesService.getUserProperties().deleteAllProperties();
```

Затем:

```javascript
refreshMenu();
```

## 🔍 ПРОВЕРКА:

После выполнения команд должны видеть в Console:

```
"Меню кэша очищен!"
"Меню обновлено!"
```

Если видите ошибки - проверьте что:
1. Вы в правильной таблице (проекте)
2. Вы скопировали команды точно
3. Нажали Enter после каждой команды

## 📞 ЧТО ДЕЛАТЬ ЕСЛИ НИЧЕГО НЕ ПОЯВИЛОСЬ:

1. **Убедитесь что сервер работает:**
   ```
   http://46.226.167.153:8000/health
   ```
   Должна появиться зелёная страница с "healthy"

2. **Проверьте что вы в правильной таблице:**
   - Это должна быть таблица MT, SK или SS (один из 3 проектов)
   - Если открыли временную таблицу - не будет работать

3. **Попробуйте жесткую перезагрузку браузера:**
   ```
   Ctrl+Shift+R (на Windows/Linux)
   Cmd+Shift+R (на Mac)
   ```

4. **Проверьте логи скрипта:**
   В Console напишите:
   ```javascript
   console.log('Test:', getMenuConfig());
   ```

   Должно вывести информацию о меню
