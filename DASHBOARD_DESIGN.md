## 📐 ОБЩЕЕ ОПИСАНИЕ

**Дашборд** - это интерактивная страница в Google Sheets для просмотра, фильтрации и анализа всех логов системы. Источники: `LOG_DEBUG` (все события) и `LOG` (синхронизация).

**Главная цель**: Быстро найти и проанализировать любую операцию в системе.

## 🔧 СЕКЦИЯ 1: ПАНЕЛЬ УПРАВЛЕНИЯ (Вверху)

### Кнопки действий:
| Кнопка | Функция | Значок |
|--------|---------|--------|
| **Обновить** | Загрузить новые логи из LOG_DEBUG и LOG | 🔄 |
| **Скачать CSV** | Экспортировать отфильтрованные логи в CSV | 📥 |
| **Очистить фильтры** | Сброс всех фильтров (вернуть состояние по умолчанию) | 🧹 |
| **Закрыть** | Закрыть дашборд и вернуться на исходный лист | ❌ |

**Поведение**:
- Кнопка "Обновить" загружает данные каждые 5 секунд (автоматически)
- "Скачать CSV" содержит только отфильтрованные строки
- "Очистить фильтры" предварительно спрашивает подтверждение

## 📋 СЕКЦИЯ 2: ПАНЕЛЬ ФИЛЬТРОВ

### 2.1 Фильтр ⏰ ПЕРИОД

**Варианты**:
- **Сегодня** - логи за сегодняшний день (00:00 - 23:59)
- **24 часа** - логи за последние 24 часа
- **7 дней** - логи за последние 7 дней
- **Другое** - пользовательский диапазон (от - до)

**Поведение**: При выборе "Другое" появляются два поля ввода для даты начала и конца.

---

### 2.2 Фильтр 🏷️ КАТЕГОРИЯ

**Доступные категории** (15 штук):
- Article (📄) - операции с артикулами
- Sync (🔄) - синхронизация
- Delete (🗑️) - удаление
- Network (🌐) - сетевые операции
- Price (💰) - работа с ценами
- Certificate (📜) - сертификация
- Invoice (📋) - счета
- Order (📦) - заказы
- Label (🏷️) - этикетки
- Spirit (🥃) - спирт/алкоголь
- Dashboard (📊) - дашборд
- Menu (📋) - меню
- Cache (💾) - кэширование
- Lock (🔒) - блокировки
- Settings (⚙️) - настройки

**Поведение**:
- Все категории по умолчанию ✅ (выбраны)
- Клик на чекбокс снимает/ставит галку
- Если все категории сняты - фильтр отключается (показываются все)

---

### 2.3 Фильтр 📊 СТАТУС

**Доступные статусы**:
- ✅ SUCCESS (успех)
- 🚀 START (начало)
- ⏳ PROGRESS (прогресс)
- ⚠️ WARNING (предупреждение)
- ❌ ERROR (ошибка)

**Поведение**:
- По умолчанию все выбраны
- Множественный выбор (AND логика)

---

### 2.4 Фильтр 📌 УРОВЕНЬ

**Доступные уровни**:
- DEBUG - отладочные логи
- INFO - информационные логи
- WARN - предупреждения
- ERROR - ошибки

**Поведение**:
- По умолчанию все выбраны
- Множественный выбор

---

### 2.5 Фильтр 🔍 ПОИСК

**Текстовый поиск**:
- Ищет в полях: **Сообщение**, **Функция**, **Детали**
- Поиск **регистронезависимый**
- Поддерживает **частичное совпадение**
- Пример: если ввести "синхр", найдёт все содержащие "синхронизация"

**Поведение**:
- Работает в реальном времени при изменении текста
- Пустое поле = поиск отключен

---

### 2.6 Кнопки фильтрации

| Кнопка | Функция |
|--------|---------|
| **Применить фильтры** | Применить все выбранные фильтры и обновить таблицу |
| **Сброс** | Вернуть все фильтры в исходное состояние (все выбраны) |

## 🗂️ СЕКЦИЯ 4: ТАБЛИЦА ЛОГОВ

### Структура колонок:

| Колонка | Содержимое | Ширина | Примечание |
|---------|-----------|--------|-----------|
| **№** | Порядковый номер | 5% | Автоиндекс |
| **Время** | дд.мм.гггг чч:мм:сс | 15% | Отсортирована по убыванию (новые сверху) |
| **Категория** | 🔄 Sync, 📄 Article и т.д. | 12% | С эмодзи, кликабельно как фильтр |
| **Статус** | ✅ SUCCESS, ❌ ERROR и т.д. | 10% | Цветная подсветка |
| **Сообщение** | Текст сообщения | 30% | Усечение с ... если длинное |
| **Функция** | Имя функции | 15% | Текст монофонтом |
| **Детали** | Краткая информация | 13% | Усечение с ... если длинное |

### Цветовая подсветка строк:

| Статус | Цвет фона | Пример |
|--------|----------|---------|
| SUCCESS | 🟢 Светлый зеленый | #E8F5E9 |
| START | 🔵 Светлый синий | #E3F2FD |
| PROGRESS | 🟡 Светлый желтый | #FFFDE7 |
| WARNING | 🟠 Светлый оранжевый | #FFF3E0 |
| ERROR | 🔴 Светлый красный | #FFEBEE |

### Интерактивные элементы в таблице:

1. **[Развернуть]** - показывает полный текст сообщения, если оно усечено
2. **[Детали]** - открывает модальное окно с полной информацией:
   - Все поля логирования
   - Полный текст параметров и результатов
   - Временная метка создания

3. **[JSON]** - открывает окно просмотра JSON:
   - Параметры (variables) в красивом формате
   - Результаты (result) в красивом формате

### Взаимодействие с таблицей:

- **Клик на категорию** - добавляет в фильтр (если ещё не добавлена)
- **Клик на статус** - добавляет в фильтр (если ещё не добавлен)
- **Клик на функцию** - может скопировать имя в буфер обмена
- **Правый клик на строку** - контекстное меню (копировать строку, экспорт)

## ⚙️ ТЕХНИЧЕСКАЯ КОНФИГУРАЦИЯ

### Источники данных:

| Источник | Лист | Используется для |
|----------|------|-----------------|
| LOG_DEBUG | Журнал логов | Все логи (DEBUG, INFO, WARN, ERROR) |
| LOG | Журнал синхро | Только логи SYNC категории |

### Частота автообновления:

- **По умолчанию**: Каждые 5 секунд
- **Можно отключить**: Кнопка "⏸️ Пауза" (вместо "🔄 Обновить")
- **Максимум загружаемых строк**: 500 (или вся история за 24ч)

### Производительность:

- **Время загрузки**: < 2 секунды
- **Время применения фильтра**: < 1 секунда
- **Размер CSV экспорта**: До 1 МБ
