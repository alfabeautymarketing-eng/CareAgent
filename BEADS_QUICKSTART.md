# Как Работать с AI Агентами и Beads

## Для Вас (Пользователь)

### Когда агент говорит "Beads в режиме read-only"

**Что это означает:**
Агент не может создавать задачи, но МОЖЕТ читать существующие. Это нормально для некоторых агентов.

**Что делать:**

**Вариант 1: Создать новую задачу**
```bash
bd create "Краткое описание того, что нужно сделать"
```
Скопируйте полученный ID (например: `AgentCare-abc`) и отправьте его агенту.

**Вариант 2: Использовать существующую задачу**
```bash
# Посмотреть список готовых задач
bd ready

# Выбрать одну из списка и отправить ID агенту
# Например: AgentCare-563
```

### Частые Команды

```bash
# Посмотреть готовые задачи
bd ready

# Создать новую задачу
bd create "Описание"

# Посмотреть все задачи
bd ls

# Синхронизировать после работы агента
bd sync

# Статус текущей работы
bd status
```

## Для AI Агентов

### Обязательный Чеклист Каждой Сессии

- [ ] Выполнить `bd ready --no-db --readonly` в начале
- [ ] Если read-only - спросить пользователя об ID
- [ ] **Если что-то непонятно - СПРОСИТЬ!** Не додумывать самому
- [ ] Назначить задачу: `bd pin <ID>`
- [ ] Работать только в рамках задачи
- [ ] Указывать ID в коммитах: `fix: AgentCare-563 - описание`
- [ ] Сообщить пользователю о необходимости `bd sync`

### Источники Правды (по приоритету)

1. **Задачи:** `.beads/` (НЕ локальные task.md!)
2. **Правила:** `AI_RULES.md` и `AI_CENTRAL_COMMAND.md`
3. **MCP Config:** `~/Library/Application Support/Claude/claude_desktop_config.json`
4. **Документация:** `docs/` в проекте

## Решение Проблем

### "bd: command not found"
```bash
# Добавить в PATH
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

# Или использовать полный путь
/Users/aleksandr/.local/bin/bd ready
```

### "Агент создал task.md в артефактах"
Это нормально для заметок, но **НЕ является** источником задач. Настоящие задачи только в Beads.

### "Разные агенты работают по-разному"
Все агенты ОБЯЗАНЫ следовать `AI_CENTRAL_COMMAND.md`. Если агент нарушает - покажите ему этот файл.

---

Прочитать [`AI_CENTRAL_COMMAND.md`](./AI_CENTRAL_COMMAND.md) перед началом работы.
